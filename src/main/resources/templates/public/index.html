Set up Google Sign-In

Firebase client credentials are not configured. Follow these steps to enable Google Sign-In:

  1. Open Firebase Console → your project → Project Settings → General
  2. Scroll to Your apps → select your Web App (or create one)
  3. Under SDK setup and configuration, copy the firebaseConfig values
  4. Paste them into src/main/resources/firebase-web-config.json
  5. Restart the application

For production: set environment variables FIREBASE_CLIENT_API_KEY and FIREBASE_CLIENT_APP_ID.
