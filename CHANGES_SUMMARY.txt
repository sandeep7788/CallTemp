10. APPLICATION ENDPOINTS
========================================

Web Pages:
  - GET /         → Serves index.html (Main application page)
  - GET /index    → Same as above (alternative path)

API Endpoints:
  - GET  /user/token           → Get Twilio access token (returns User JSON)
  - POST /call/voice           → Handle outgoing voice calls (TwiML response)
  - POST /call/direct-client   → Handle direct client calls (TwiML response)

Static Resources:
  - /css/site.css              → Application styles
  - /js/quickstart.js          → Twilio client JavaScript

========================================
11. HOW TO RUN
========================================

1. Configure Twilio credentials in application.properties:
   - twilio.account_sid
   - twilio.auth_token
   - twilio.trial_number
   - twilio.twiml.app.sid
   - twilio.api.key
   - twilio.api.secret

2. Build and run:
   ```
   mvn clean install
   mvn spring-boot:run
   ```

3. Access the application:
   - Open browser: http://localhost:8080/
   - The page will automatically request a token from /user/token
   - You can make calls using the Twilio client

12. PROJECT STRUCTURE
========================================

Controllers:
  - IndexController: Serves HTML pages
  - UserController: REST API for user tokens
  - CallController: REST API for TwiML voice responses

Services:
  - UserService: Generates Twilio access tokens
  - CallService: Creates TwiML voice responses

Model:
  - User: Record with identity and token

Constants:
  - AppMessages: Static message strings
  - AppStatics: Static application state
