========================================
WHY v1.14 INSTEAD OF v2.x?
========================================

Twilio has two SDK versions:

v1.x (v1.14 - what we're using):
  ✅ Stable, well-documented
  ✅ Uses static methods (Twilio.Device.setup)
  ✅ Compatible with our code
  ✅ Still supported
  ✅ No code changes needed

v2.x (newer, but different API):
  ⚠️ Uses constructor (new Twilio.Device)
  ⚠️ Different event handling
  ⚠️ Requires code rewrite
  ⚠️ More complex setup

For learning purposes, v1.14 is perfect!
