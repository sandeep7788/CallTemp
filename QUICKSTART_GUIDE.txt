HOW TO RUN THE APPLICATION
========================================

Method 1: Using Maven
---------------------
1. Open terminal in project directory
2. Run: mvn spring-boot:run
3. Wait for "Started TwilioClientSpringApplication"
4. Open browser: http://localhost:8080/

Method 2: Using IntelliJ IDEA
-----------------------------
1. Reload Maven project (Ctrl+Shift+O or File → Reload All from Disk)
2. Run TwilioClientSpringApplication.java
3. Open browser: http://localhost:8080/

Method 3: Using JAR
-------------------
1. Build: mvn clean package
2. Run: java -jar target/tempp-0.0.1-SNAPSHOT.jar
3. Open browser: http://localhost:8080/

AVAILABLE URLS
========================================

Web Interface:

  http://localhost:8080/index     → Same as above

API Endpoints:
  GET  /user/token                → Get Twilio access token
  POST /call/voice                → Handle voice calls (TwiML)
  POST /call/direct-client        → Direct client calls (TwiML)

Static Resources:
  /css/site.css                   → Application styles
  /js/quickstart.js               → Client JavaScript

========================================
APPLICATION WORKFLOW
========================================

1. User opens http://localhost:8080/
2. Page loads index.html from templates/public/
3. JavaScript (quickstart.js) executes
4. Calls GET /user/token to get Twilio access token
5. UserController → UserService generates token
6. JavaScript sets up Twilio.Device with token
7. User can make/receive calls through the interface
8. Call requests go to /call/voice endpoint
9. CallService generates TwiML responses
10. Twilio processes TwiML and connects calls

========================================
CONFIGURATION NOTES
========================================

The application.properties contains:
  - twilio.account_sid      (Your Twilio Account SID)
  - twilio.auth_token       (Your Auth Token)
  - twilio.trial_number     (Your Twilio Phone Number)
  - twilio.twiml.app.sid    (TwiML App SID)
  - twilio.api.key          (API Key)
  - twilio.api.secret       (API Secret)

⚠️  IMPORTANT: Replace the masked values (******) with your
    actual Twilio credentials before using the application.

To get Twilio credentials:
1. Sign up at https://www.twilio.com/
2. Get Account SID and Auth Token from Dashboard
3. Create a TwiML App
4. Create API Keys

========================================
TROUBLESHOOTING
========================================

Problem: Port 8080 already in use
Solution: Change port in application.properties:
          server.port=8081

Problem: 404 when accessing /
Solution: Already fixed! Both / and /index work now.

Problem: Cannot get token
Solution: Check that UserController endpoint is working:
          curl http://localhost:8080/user/token

Problem: Compilation errors in IDE
Solution: Reload Maven project (IntelliJ: Ctrl+Shift+O)

Problem: Lombok errors
Solution: Ensure Lombok plugin is installed in IDE
          IntelliJ: Settings → Plugins → Lombok

TESTING THE APPLICATION
========================================

1. Start the application
2. Open http://localhost:8080/
3. You should see:
   - "Requesting Access Token..."
   - "Got an access token."
   - "Twilio.Device Ready!"
   - Your client name displayed
   
4. Try making a call:
   - Enter a phone number (e.g., +1234567890)
   - Click "Call" button
   - Check browser console for logs

5. Check server logs:
   - Look for "Generating user token"
   - Look for "Creating voice response"
